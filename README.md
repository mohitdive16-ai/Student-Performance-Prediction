# 🎓 Student Performance Prediction

A Machine Learning project that predicts whether a student will **Pass or Fail** based on their academic performance.

## 📌 Project Overview

This project uses Machine Learning to predict student performance using four important features:

- Study Hours
- Attendance
- Previous Marks
- Assignments

The model predicts:

- `1` → Pass
- `0` → Fail

## 🤖 Machine Learning Algorithm

**Logistic Regression**

Logistic Regression is used because this is a **binary classification problem**, where there are only two possible outcomes:

```text
0 → Fail
1 → Pass
